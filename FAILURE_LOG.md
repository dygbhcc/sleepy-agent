# Failure log

Every day something breaks. This file keeps the evidence: what I expected,
what happened, why, and what I changed. Entries include mistakes caused by my
own tests and assumptions, because those are the most useful ones.

In Sleepy these were the first real failures, found only by reading the output | Fixed on D6: the QA gate rejects both (`TestGateRejectsATooShortScript`, `TestGateRejectsOneSentenceRepeatedSixtyTimes`, the second one is caught by the repetition check since its length is fine), and the naive `internal/pipeline` package is gone |
